# 🌸 Chá de Bebê da Maitê | Leonardo & Isabella 🍼

Site moderno, responsivo e interativo criado especialmente para o Chá de Bebê da **Maitê**, filha de **Leonardo & Isabella**.

---

## ✨ Funcionalidades

- 🎁 **Lista de Presentes Inteligente:**
  - 32 itens pré-cadastrados com categorias (Fraldas, Higiene & Banho, Alimentação, Quarto, Passeio, Roupas, Brinquedos).
  - Modal de confirmação inteligente (*"Tem certeza que deseja reservar este presente?"*).
  - Reserva imediata sem necessidade de cadastro burocrático dos convidados.
  - Barra de progresso ao vivo com contagem de itens disponíveis e reservados.
  - Filtro por categoria, status (Disponíveis / Reservados) e campo de busca.

- 💌 **Confirmação de Presença (RSVP):**
  - Confirmação de presença (Sim / Não).
  - Seleção de quantidade de pessoas (Adultos e Crianças com controle numérico).
  - Inserção dinâmica dos nomes dos acompanhantes.
  - Telefone / WhatsApp e recado de carinho.
  - Chuva de confetes comemorativa após o envio.

- 💖 **Mural de Amor / Recados:**
  - Mural onde familiares e amigos podem deixar mensagens acolhedoras e dar corações.

- 👑 **Painel dos Papais (Leonardo & Isabella - Admin):**
  - Acesso protegido por senha/PIN (padrão: `1234`).
  - Relatório completo de presenças com lista de convidados e contagem total de adultos e crianças.
  - Exportação da lista de confirmações para **Excel / CSV** com 1 clique.
  - Gestão total de presentes (adicionar novos, editar, excluir ou liberar itens reservados).
  - Personalização de data, horário, endereço, link do Google Maps e chave Pix.

- 📱 **100% Responsivo e Otimizado:**
  - Visual suave em tons *Blush Rosé*, *Creme* e *Dourado*.
  - Perfeito para visualização no celular via WhatsApp.

---

## 🛠️ Tecnologias Utilizadas

- **React 18 + Vite**
- **Tailwind CSS** (Tema personalizado bebê)
- **Lucide Icons**
- **Canvas-Confetti**

---

## 🚀 Como Executar Localmente

1. Instale as dependências:
   ```bash
   npm install
   ```

2. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```

3. Abra no navegador:
   ```
   http://localhost:5173
   ```
