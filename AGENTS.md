# Diretrizes do Projeto - Chá da Maitê

## Regras de Testes e Dados
1. **Limpeza Obrigatória Pós-Testes**: Sempre que forem executados testes no site ou no banco de dados, todos os dados inseridos exclusivamente para teste DEVEM ser removidos imediatamente após a conclusão dos testes.
2. **Exclusividade de Testes**: Somente dados de teste podem ser removidos durante a limpeza de testes. Nunca alterar, ocultar ou remover dados legítimos de convidados reais.
3. **Sem Travas Artificiais ou Hardcoded**: Nenhum convidado real deve ter regras de proteção fixa ou hardcoded no código que impeçam sua edição ou exclusão. O administrador deve poder excluir a presença, o presente ou o recado de qualquer convidado a qualquer momento pelo Painel Administrativo.
